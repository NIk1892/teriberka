# Звёздное небо главной страницы

Семь рисунков: Кассиопея, Лебедь, Лира, Цефей, Геркулес, Северная Корона и Волопас.
Декоративный фон главной страницы в тёмной
теме. До 699 px используется портретная композиция, от 700 px — горизонтальная.
Прокрутка перемещает вид по общей карте неба; это не расчёт горизонта Териберки на текущую дату.

Координаты J2000, звёздные величины Vmag и цвет B−V взяты из
[Bright Star Catalogue, V/50 (Hoffleit & Warren, 1991)](https://cdsarc.cds.unistra.fr/viz-bin/ReadMe/V/50?format=html).
Сохранён небольшой фрагмент каталога в stars.json; при открытии сайта запросов
к каталогу нет. Соединения сверены с картами IAU / Sky & Telescope:
[Кассиопея](https://iauarchive.eso.org/public/images/detail/cas/),
[Лебедь](https://iauarchive.eso.org/public/images/detail/cyg/),
[Лира](https://iauarchive.eso.org/public/images/detail/lyr/),
[Цефей](https://iauarchive.eso.org/public/images/detail/cep/),
[Геркулес](https://iauarchive.eso.org/static/archives/images/screen/her.jpg),
[Северная Корона](https://iauarchive.eso.org/public/images/detail/crb/),
[Волопас](https://iauarchive.eso.org/public/images/detail/boo/).
У Геркулеса и Волопаса оставлены основные линии рисунка, без части слабых ответвлений.

Все звёзды построены в одной стереографической проекции с центром RA=330°, Dec=55°,
общим поворотом около −50.618° и одинаковым масштабом по обеим осям. Ориентация карты
одинакова на телефоне и широком экране; настольный вариант равномерно увеличен. Отдельные
созвездия не растягиваются и не переставляются. Телефон обрезает поле по краям,
а горизонтальная композиция целиком вписывается в окно. Более ярким звёздам соответствует больший видимый диск и ореол;
масштаб яркости сжат для экрана. Мерцание — художественная имитация, с пятью фазами;
при prefers-reduced-motion мерцание и движение отключаются. Поля data-hr и data-magnitude позволяют
сопоставить основные звёзды с каталогом.

Для пересоздания компонента: `node docs/design/mobile-night-sky/generate.mjs`.
Стили находятся в wwwroot/css/home.css, движение — в wwwroot/js/night-sky.js.
При прокрутке вниз всё небо движется строго снизу вверх, без бокового смещения и
вращения. При прокрутке вверх движение обратное. Карта заранее ориентирована так,
чтобы новые созвездия входили снизу. Начальная позиция — со стороны Волопаса; путь
проходит прежний участок в обратном порядке. От начала главной до появления морского
блока смещение составляет −675 единиц портретного SVG и около −1558 единиц настольного SVG.
Оба варианта проходят тот же участок каталога, с учётом масштаба. Звёзды не добавляются
случайно и не переставляются по отдельности.
Сглаживание длительностью около 90 мс работает через requestAnimationFrame только
во время движения. После остановки нет постоянного цикла. Смена размера окна,
раскрытие содержимого и восстановление позиции страницы учитываются автоматически.
В светлой теме и скрытой вкладке движение приостанавливается; без JavaScript или
при prefers-reduced-motion остаётся статичный фон. Каталог загружается только при
генерации компонента, браузер получает готовый SVG.

Фон не участвует в потоке страницы и
не принимает касания; исходный эффект снега существует отдельно.

Морская зона у футера имеет непрозрачное основание `background-color: var(--bg)`
в app.css. Она перекрывает фиксированное небо с самого начала берегового блока,
поэтому звёзд нет в воде, включая её полупрозрачный WebGL-слой и CSS-фоллбек.
