# ТериберкаКрай

Обновление 23.09.2026 по эскизу владельца: контур Кольского полуострова,
точка на северном побережье, силуэт скелета левиафана, бирюзовый и тёмно-синий цвета.
По уточнению владельца слово «край» увеличено, знак на телефоне — 40 px.

- `logo-on-dark.svg` — горизонтальный логотип с прозрачным фоном для тёмных поверхностей.
- `logo-on-light.svg` — горизонтальный логотип с прозрачным фоном для светлых поверхностей.
- `../../src/frontend/ui.public.web/wwwroot/img/brand-mark.svg` — векторный знак;
  компонент `BrandLogo.razor` использует его с локализованным названием и цветом темы.
- `../../src/frontend/ui.public.web/wwwroot/favicon.svg` — упрощённый знак вкладки.
- `../../src/frontend/ui.public.web/wwwroot/img/og-teriberka-leviathan.jpg` — актуальное превью ссылки, 1200×630.

Превью создано встроенным инструментом imagegen по исходному изображению владельца.
Первое задание сохранено в `preview-prompt.txt`, правка с левиафаном — в
`leviathan-preview-prompt.txt`. Актуальный исходник генерации:
`og-teriberka-leviathan-source.png`. JPEG подготовлен из него для сайта без изменения композиции.
SVG-знак и горизонтальные версии подготовлены отдельно, чтобы сохранять чёткость
в малом размере. Шрифт экспортных SVG: Segoe UI с системными запасными вариантами;
на сайте название остаётся обычным локализованным текстом.

Новая карточка использует отдельный URL; предыдущие версии сохранены для существующих ссылок.
